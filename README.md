# Marigold Social — Casual Dining Restaurant

An all-day Indian kitchen & bar on 100 Feet Road, Indiranagar. Charcoal grills, coastal curries, and plates made for passing around.

## Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- GSAP & ScrollTrigger for animations
- Node.js lightweight static server

## Running Locally
To run the site locally:
```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.
